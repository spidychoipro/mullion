# Mullion

> Arc 스타일의 윈도우 브라우저. 오픈소스. 엔진은 갈아끼운다.

Arc는 macOS 전용으로 방향을 잡으면서 윈도우 쪽에 남는 선택지가 없어졌다. Mullion은 그 자리를 채우려고 시작한 프로젝트다. 이름은 창문에서 유리 칸과 칸을 갈라주는 세로 기둥(mullion)에서 왔다. 하나의 창을 여러 칸으로 쪼개 쓰는 방식 — 사이드바 탭, 스페이스, 분할 뷰 — 을 그대로 가리킨다.

## 목표

- Arc의 UX를 윈도우에서 그대로: 세로 사이드바 탭, 스페이스, 분할 뷰, 커맨드바
- 엔진 교체 가능: 기본은 Chromium, 원하면 Gecko. 탭마다 다른 엔진도 최종 목표
- 로컬 우선: 계정 없이도 모든 기능이 완전히 동작
- MIT 라이선스, 오픈소스

## 왜 엔진을 갈아끼우나

한 엔진에 묶이면 그 엔진의 정책에 같이 묶인다. 확장 API, 광고 차단, 렌더링 결과, 배포 경로까지 전부. 그래서 셸(창·탭·스페이스·UI)과 엔진 어댑터를 분리하고, 셸은 "이 탭을 어떤 엔진으로 띄울지"만 알게 만든다. 구조는 [docs/architecture.md](docs/architecture.md) 참고.
